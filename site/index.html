How this page reached you

A static site in nginx, running as three pods on a k3s cluster at home. A Cloudflare Tunnel publishes it with no open ports, and Flux deploys every change from Git. The dots below light up each time your browser checks in.

Nodes
3
Site pods
3
Tunnels
2
  1. EdgeCloudflare

    DNS, TLS and cache. My home IP stays hidden.

  2. LinkTunnel

    Two cloudflared pods, one on each Pi, dial out to Cloudflare. Nothing is open on my router.

  3. IngressTraefik

    The k3s built-in ingress routes ajacobs.dev to the site's Service.

  4. WorkloadPods

    Three nginx:alpine pods with the site built into the image.

  5. ComputeNodes

    A Proxmox VM (amd64) and two Raspberry Pis (arm64).

Deploysgit push, then GitHub Actions builds for amd64 and arm64, GHCR stores the image and Flux applies it. Rolling back is one git revert.
